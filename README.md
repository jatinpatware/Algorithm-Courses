# Algorithm Courses

C++ implementations of algorithms and data structures from the **Coursera Algorithms Specialisation** (Stanford / Tim Roughgarden).

## Modules

| Module | Topics Covered |
|--------|---------------|
| [Divide and Conquer](./Divide_and_conquer/) | Merge sort, quicksort (comparison counting), inversion pairs, Karger's min-cut, long multiplication |
| [Greedy & Dynamic Programming](./Greedy_and_dynamic/) | Huffman coding, clustering (Kruskal's / big-graph variant), dynamic programming foundations |
| [Shortest Path & Graph Algorithms](./shortestpath_and_graph/) | Dijkstra, BFS/DFS, Bellman-Ford, graph search primitives |
| [Shortest Path Revisited & NP-Complete](./Shortest_path_revisited_and_npcomplete/) | All-pairs shortest paths, Floyd-Warshall, NP-completeness survey |

## Language

C++ — standard STL, no external dependencies.
